    Recipe：宿主接入与 Profile 注入¶

    1. 场景与非场景¶

    适用：需要描述已登记宿主（claude/codex）、探测或规划宿主接入，并向 Foundation 注入具体宿主 Profile 与受信 driver。

    不适用：需要 host apply/install/update/uninstall（明确 unsupported）；需要 Qoder 完整 driver（该宿主 unsupported）。

    2. 架构选择及能力 ID¶

    首选能力：foundation.kit.host（describeHost / probeHost / buildHostAdapter / planHost）与 foundation.profile.extension-spi（verifyProfile）。宿主差异声明在 foundation.profile.hosts。

    3. 前置条件与信任边界¶

    • 宿主 Profile 已在 profiles/hosts 登记；受信 driver 仅 claude-version-v1 / codex-version-v1。
    • 信任边界：Profile 入口必须是 JSON 数据资源，公共核心不导入 profiles/；coreOwned 为禁入目标。

    4. 最小命令与代码¶

    # 描述已登记宿主
npm exec -- skill-family-kit adopt-plan host-describe --host claude --hosts-root profiles/hosts

# 只读探测（默认不 spawn）
npm exec -- skill-family-kit adopt-plan host-probe --host claude --hosts-root profiles/hosts

    import { describeHost, probeHost, planHost } from "skill-family-engineering-kit";
import { verifyProfile } from "profiles/spi/index.mjs";

const desc = describeHost("claude"); // 受支持宿主描述
const facts = probeHost("claude", { allowSpawn: false });
const plan = planHost(desc, facts);
const spi = verifyProfile({ profileRoot: "profiles/public-plugin" }); // SPE0000

    以上命令与代码展示了 describe/probe/plan 的只读机制，以及用 verifyProfile 校验 Profile 声明。

    5. 预期输出与证据¶

    describeHost 返回宿主描述，probeHost 返回只读探测事实，planHost 返回接入计划，verifyProfile 返回 SPE0000 等结果码。证据：packages/skill-family-engineering-kit/test/host.test.mjs 与 fixtures/generic-profile-extension-conformance/verify.mjs。

    6. 安全/失败负例¶

    # 负例：apply 稳定拒绝
npm exec -- skill-family-kit adopt-plan host-apply --host claude --hosts-root profiles/hosts
# 退出码 2：host apply is not implemented in the read-only Phase D slice

    // 负例：qoder 为 unsupported
describeHost("qoder"); // 抛错：support = "unsupported"

    7. 可复制验证命令¶

    node --test packages/skill-family-engineering-kit/test/host.test.mjs \
           fixtures/generic-profile-extension-conformance/verify.mjs

    8. 调用方继续拥有的业务逻辑¶

    • 宿主具体业务语义。
    • 宿主应用（apply）的最终落地（当前不在 Foundation 范围）。

    9. 升级与回滚注意事项¶

    • 宿主接入线只支持 describe/build/probe/plan；apply 稳定拒绝，安装/卸载/更新未实现。
    • Qoder 完整 driver 为 unsupported，只参考其结构，不声称已在 Qoder 运行；升级新增受支持宿主须登记 descriptor 并绑定受信 driver。
