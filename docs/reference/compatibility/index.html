    兼容性与支持矩阵¶

    本页给出包、Contracts、Node 与宿主的支持矩阵和升级规则。所有版本号从机器真源复算，不凭记忆。

    包版本矩阵¶

    包 版本（package.json） 角色 发布状态
    skill-family-contracts 0.2.1 Contracts 1.4.0 机器契约 公开发布目标（private: false）
    skill-family-harness-node 0.2.1 Contracts 的 Node 薄机制运行时 公开发布目标
    skill-family-engineering-kit 0.2.1 四个工程命令（CLI skill-family-kit） 公开发布目标
    工作区仓 0.2.1 私有父工作区（private: true） 仅开发真源

    契约权威版本（CONTRACTS_VERSION）为 1.4.0，npm 包版本为 0.2.1，两套版本并行，不混用。

    Node 支持矩阵¶

    • 引擎要求：>=22.22.2 <23（锁定 major 22）。
    • 精确 floor：.node-version 取 22.22.2，作为运行时版本判定的机械真源。
    • pnpm：10.30.0（package.json 的 packageManager）。
    • projen：0.101.23（受管工程文件唯一生成入口）。

    低于 floor 的 Node 版本不能替代权威结果；第二语言实现首版为 0。

    Contracts 版本与稳定性¶

    • 顶层对象：18 类（以 packages/skill-family-contracts/src/registry.json 为唯一真源）。
    • 强制机械规则：9 条，预算上限 20、绝对上限 30。
    • kernel 协议：skill-family.kernel.operation（stable），Contracts 1.4.0。
    • Schema 校验器：Ajv 8.20.0（精确 pin），支持 draft-07 与 2020-12。
    • 错误码：冻结登记表，码只增不改、不复用。

    宿主支持矩阵¶

    宿主 support driver 备注
    claude supported claude-version-v1 技能路径由 Profile 决定
    codex supported codex-version-v1 技能路径固定 .agents/skills
    qoder unsupported 无 No auditable non-interactive host driver is frozen

    宿主接入线当前只支持 describe/build/probe/plan；apply 稳定拒绝，安装/卸载/更新均未实现。

    升级规则¶

    • 包版本：三个叶子包必须同步版本，禁止单包漂移；新增组件须说明删除它会让两个以上真实消费者重复实现。
    • Contracts：对象集合固定 18 类，新增需 ADR；错误码冻结不漂移；Schema 变更作为新的合同版本任务进行。
    • Kit 命令：顶层命令固定 4 个（scaffold/adopt-plan/projection/check），不扩张；REFUSED_MUTATION_FLAGS 在 CLI 入口即拒。
    • Node/pnpm/projen：跟随 .foundation/version-lock.json 与 package.json 的精确锁定，升级须经 pnpm synth 重新生成受管投影。
    • 宿主：新增受支持宿主须登记 descriptor 并绑定受信 driver；unsupported 宿主（如 qoder）只参考结构，不声称已在其上运行。

    反兼容边界（明确不支持）¶

    • host apply / install / update / uninstall（unsupported）。
    • Qoder 完整 driver（unsupported）。
    • 二进制 adapter source（仅文本闭包）。
    • 远端发布与全部远端写入（归 release-skill）。
    • 业务状态机、模型编排、领域审计语义（分别留消费者 / loop-agent / 独立审计）。
