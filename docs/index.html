    Skill Family Foundation Workspace¶

    Skill Family 生命周期的公共工程基础设施父工作区。本仓提供机器契约（Contracts）、Node 薄运行时（Harness）、工程工具包（Engineering Kit）、Profile SPI、完全虚构的通用样例（fixture）和工程文档骨架。

    当前状态¶

    本仓是一套开发中的首版骨架。版本、发布、Pages 与 Git 等动态状态唯一见 当前产品状态；许可证已批准为 Apache License 2.0，版权主体为广州市风荷科技有限公司，规范全文见根级 LICENSE。

    本工作区永久 private，是唯一开发真源；公开边界只有三个版本化发布镜像与 npm tarball，钉住的消费坐标与发布状态唯一见 当前产品状态。

    产品级的唯一状态页是 当前产品状态，由 node scripts/docs/fact-check.mjs 对照机器真源机械校验；其他页面不承载第二套状态口径。

    首版组成¶

    组成 路径 职责
    Contracts packages/skill-family-contracts 机器可执行工程结构和机制协议的唯一权威
    Harness packages/skill-family-harness-node 只实现 Contracts 定义的机制协议，不拥有业务语义
    Engineering Kit packages/skill-family-engineering-kit 只提供 scaffold、adopt-plan、projection、check 四个顶层命令
    Profile 种子 profiles/public-plugin 公开插件形态的 Profile 种子
    虚构样例 fixtures/generic-profile-extension-conformance 完全虚构的扩展一致性样例

    包清单、Profile、fixture 与顶层命令以 .foundation/skeleton-manifest.json 为机器真源；工具版本锁定见 .foundation/version-lock.json。

    写作边界¶

    文档只消费机器真源构成的冻结事实包（manifest、package.json、Contracts 登记等），由 node scripts/docs/fact-check.mjs 机械校验。模型名、凭据和调度信息不进入文档，也不进入 Contracts；详见 架构边界。
